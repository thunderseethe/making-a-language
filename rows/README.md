# Row Type Checker

This extends our base type checker with support for row types.

It is the full implementation of the ideas explained in [part 3 of the making a language series](https://thunderseethe.dev/posts/row-types/)
We introduce the idea of a Row as a mapping from labels to types, and set-up the required machinery to infer rows from new AST nodes and solve them during unification.

Our type checker is getting larger so we've split it out into multiple files for this stage:

* `ast.rs` - this is our AST implementation
* `ty.rs` - our Type implementation and some helper functions
* `infer.rs` - this is where we create our type constrains from an input AST
* `unification.rs` - solves constraints (generated by infer.rs) and produces a type substitution solving inferred type variables
* `subst.rs` - provides functions to substitute type variables for their solved row types.

Finally, `lib.rs` ties it all together in it's `type_infer` method (same as in `base`).
