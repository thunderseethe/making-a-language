`lsp` ties all our passes into our final compiler.
It builds a query-based compiler and then uses it to implement a language server for the Language Server Protocol (LSP).
See the corresponding [blogpost](https://thunderseethe.dev/posts/lsp-base) for an explanation of how it works.

Check out the [playground](https://thunderseethe.dev/making-a-language) to see our compiler working live.
